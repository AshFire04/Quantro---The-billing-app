Quantro: App Map

A one-page guide to where things live in the code. It is a snapshot of commit a7d5c44 and can drift as the app changes.

What the app is

Quantro is a simple website for a shop owner. Making a bill updates the stock by itself, so there is one set of records instead of two. It is a Flask (Python) app with a SQLite database file, and it works on a laptop or a phone. Everything is scoped to the signed-in shop.

  • Billing: build a bill, with discounts, offers, shipping and payments. Saving it lowers stock.
  • Inventory and Customers: products with stock levels, and the customer list.
  • Past bills: find, edit, cancel and download bills, and print them on A5.
  • Home, Profit and Shop Details: summaries, profit figures, and each shop's own settings.

A practice to reuse

Put the rules in one place and test them directly. In Quantro, the money and stock rules sit in app/services/billing.py, which has no web code in it. That is why tests/test_billing.py can call save_bill() straight away and prove that an oversell is refused and that a failed save changes nothing. When the screen changed many times during review, the rules stayed trustworthy, and the 277 tests caught mistakes early.

On another project, ask the agent to keep the important rules in plain functions and to write a test for the failure case first. Then any later change can be checked with one command.

Run it again

Start steps
  1. Install: pip install -r requirements.txt
  2. Optional sample shop: python seed.py
  3. Run: python -m flask --app app run, then open http://localhost:5000. Add --host 0.0.0.0 to open it on a phone on the same Wi-Fi.
  4. Check everything: python -m pytest -q
